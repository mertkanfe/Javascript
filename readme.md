# 🚀 JavaScript Projeleri

JavaScript öğrenme sürecimde pratiğimi geliştirmek amacıyla hazırladığım, **HTML5, CSS3 ve JavaScript** kullanılarak geliştirilen 10 farklı projeden oluşan çalışma serisi.

Bu projelerde herhangi bir framework veya kütüphane kullanılmamıştır. Her proje, JavaScript'in farklı konularını uygulamalı olarak öğrenmek ve geliştirmek amacıyla hazırlanmıştır.

## 🚀 Kurulum

Repoyu klonlayın:

```bash
git clone https://github.com/mertkanfe/proje-repo-adi.git
```

Proje klasörüne girin:

```bash
cd proje-repo-adi
```

Ardından istediğiniz projenin klasörünü açarak `index.html` dosyasını çalıştırabilirsiniz.
